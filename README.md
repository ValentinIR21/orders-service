<h1>Простой HTTP сервер на Go с PostgreSQL, Redis, Kafka</h1>
<h2>Возможности:</h2>

- Хранение данных в PostgreSQL

- Кэширование для доступа по ID с использованием Redis
  
- Заказы сохраняются в БД через Kafka
  
<h2>API:</h2>
<h3>Пример запроса JSON:</h3>

**Метод**: POST /order

{
    "product": "Ноутбук",
    "description": "Игровой ноутбук",
    "price": 75000
}

**запросы**:

- ```http://localhost:9091/order``` - Создание товара (принимает тело в формате JSON)

- ```http://localhost:9091/orders``` - Получение всех товаров

- ```http://localhost:9091/order/{id}``` - Получение товара по id

<h2>Запуск шарманки:</h2>

- ```docker-compose up --build```

<h2> Архитектура </h2>

- Go - приложение (:9091)

- PostgreSQL (:5432)

- Redis (:6379)

- Kafka (:9092)
